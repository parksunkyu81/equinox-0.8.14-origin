# km/h 고정 및 크루즈 버튼 정렬 동작

## 단위

이 소스는 `IsMetric` 설정을 사용하지 않습니다.

- 현재속도: `carState.vEgo`(m/s) × 3.6 → km/h
- 크루즈 설정속도: km/h
- 적용 제한속도: km/h
- 도로·카메라·구간 제한속도: km/h
- 설정 화면의 `Use Metric System` 토글 제거

## 버튼 동작

RES+와 SET-를 동일하게 처리합니다.

- 짧게 누름: 현재 설정속도보다 높은 다음 5km/h 경계
- 길게 누름: 현재 설정속도보다 높은 다음 10km/h 경계
- 길게 유지해도 한 번만 적용
- 길게 누른 뒤 놓을 때 5km/h가 중복 적용되지 않음

예시:

- 63 → RES+ 짧게 → 65
- 63 → RES+ 길게 → 70
- 63 → SET- 짧게 → 65
- 63 → SET- 길게 → 70
- 65 → 짧게 → 70
- 70 → 길게 → 80

주의: 요청에 따라 SET-도 감속이 아니라 설정속도를 올리는 버튼으로 동작합니다.
