# 콤마 페달 운용 및 개발 지침

이 문서는 브레이크를 운전자가 직접 조작하고 콤마 페달이 가속만 보조하는 GM 차량용 종방향 제어 원칙을 정의한다.

## 핵심 원칙

1. 일반 주행의 기본 가속 상한은 `longitudinal_planner.py`의 속도별 앞차 추종 상한을 사용한다.
2. `carcontroller.py`는 양의 가속 요청에 플래너 상한을 직접 적용한다.
3. 별도의 `pedal_follow.py`, `pedal_safety.py`, 고정 `1.0 m/s²` 상한, 페달 추종 스무더를 사용하지 않는다.
4. 앞차 추종 거리와 상대속도에 따른 가감속 계획은 종방향 MPC와 플래너가 담당한다.
5. 브레이크 입력은 모든 콤마 페달 가속 명령보다 우선한다.
6. 정차 상태와 0.5 km/h 이하에서는 자동 페달 가속을 차단한다.
7. 운전자가 가속페달을 밟는 동안에는 자동 페달 명령을 보내지 않는다.

## 속도별 기본 가속 상한

`longitudinal_planner.py`의 `_A_CRUISE_MAX_V_FOLLOWING`을 선형 보간한 값이 최종 양의 가속 상한이다.

```text
최종 양의 가속 = min(제어기 가속 요청, calc_cruise_accel_limits(현재 속도)[1])
```

| 내 차 속도 | 기본 가속 상한 |
|---:|---:|
| 0 km/h | 1.478 m/s² |
| 10 km/h | 1.558 m/s² |
| 20 km/h | 1.470 m/s² |
| 30 km/h | 0.930 m/s² |
| 40 km/h | 0.890 m/s² |
| 50 km/h | 0.870 m/s² |
| 60 km/h | 0.874 m/s² |
| 70 km/h | 0.902 m/s² |
| 80 km/h | 0.917 m/s² |
| 90 km/h | 0.887 m/s² |
| 100 km/h | 0.814 m/s² |

10 km/h 단위 사이에는 다음 기준점이 추가로 존재한다.

| 내 차 속도 | 기본 가속 상한 |
|---:|---:|
| 1 km/h | 1.619464 m/s² |
| 15 km/h | 1.694 m/s² |
| 55 km/h | 0.860 m/s² |
| 85 km/h | 0.924 m/s² |

기준점 사이 값은 선형 보간하며, 100 km/h 이상은 마지막 값인 `0.814 m/s²`를 유지한다.

## 실제 가속이 더 낮아지는 조건

표의 값은 최종 양의 가속 요청에 적용되는 최대값이다. 실제 명령은 다음 조건에 의해 더 낮아질 수 있다.

- 종방향 MPC의 앞차 거리 및 상대속도 계획
- 앞차 감속과 정지 예측
- 코너 총가속도 제한
- 운전자 주의 저하 감속
- PID 및 차량 인터페이스 제한
- 운전자 브레이크 입력

## 정차 및 운전자 입력

별도의 자동 출발 부스트나 수동 출발 인계 상태 머신을 사용하지 않는다. 다음 조건에서는 콤마 페달 출력을 0으로 유지한다.

- 차량이 정차 상태일 때
- 차량 속도가 0.5 km/h 이하일 때
- 콤마 페달 활성화 최소속도 이하일 때
- 운전자가 브레이크를 밟을 때
- 운전자가 가속페달을 밟을 때
- ACC 또는 제어기가 비활성화되어 있을 때

## 구현 위치

- 속도별 가속 상한과 보간: `selfdrive/controls/lib/longitudinal_planner.py`
- 최종 상한 직접 적용 및 페달 CAN 명령: `selfdrive/car/gm/carcontroller.py`
- 종방향 PID와 브레이크 우선 처리: `selfdrive/controls/controlsd.py`
- 앞차 거리 계획: `selfdrive/controls/lib/longitudinal_mpc_lib/long_mpc.py`
- 동적 추종 거리: `selfdrive/controls/lib/dynamic_follow/__init__.py`

## 진단 데이터

기존 로그 스키마와의 호환성을 위해 `pedalFollow*`, `pedalLaunch*`, `pedalDeadzone*` 필드는 유지한다. 제거된 별도 페달 안전 기능에 해당하는 상태 필드는 `0` 또는 `false`를 기록하며, `pedalComfortAccelCap`은 현재 속도의 플래너 가속 상한을 기록한다.

## 변경 시 확인사항

- `pedal_follow.py`와 `pedal_safety.py` import가 다시 추가되지 않았는지 확인한다.
- 고정 `1.0 m/s²` 상한이 다시 추가되지 않았는지 확인한다.
- 최종 양의 가속 상한이 `calc_cruise_accel_limits(vEgo)[1]`과 일치하는지 확인한다.
- 음의 가속 요청을 양의 가속 상한으로 잘못 잘라내지 않는지 확인한다.
- 브레이크 입력 한 프레임 안에 콤마 페달 출력이 0이 되는지 확인한다.
- 정차 상태와 운전자 가속페달 입력 중 자동 페달 출력이 차단되는지 확인한다.
- 실차 적용 전 `pedalComfortAccelCap`, 요청 가속도, 적용 가속도, 차간거리와 상대속도를 함께 확인한다.

이 기능은 운전자 보조 기능이다. 폐쇄된 환경에서 단계적으로 검증하고, 운전자는 항상 직접 제동할 준비를 해야 한다.
